# Contribute

Start with a focused issue that describes the user problem.
State whether the work affects an agent workflow, the interface, or a publication adapter.

1. Read AGENTS.md and docs/architecture.md.
2. Create a branch for the change.
3. Use fictional data and mock accounts in tests.
4. Preserve content versions and permission boundaries.
5. Add meaningful tests for changed workflow behavior.
6. Run `npm test` and `npm run check`.
7. Inspect interface changes in a browser at desktop and phone widths.
8. Update the support table and relevant guides.
9. Open a pull request with the problem, change, and verification result.

Do not commit credentials, private brand profiles, customer messages, or live platform data.
Do not claim live support from a mocked response.
New adapters need account checks, a commit checkpoint, recovery behavior, and a truthful receipt.

Use simple English and short sentences in user-facing text.
Keep code and example asset licenses separate.
Contributions to the engine code use the repository's MIT License.
