# Interface fonts

The engine uses the approved VIRAX type families:

- Orbitron Regular and Medium for display text.
- Science Gothic Regular and Medium for the interface and body text.

The unmodified font files use the SIL Open Font License 1.1.
Keep the accompanying license files with any redistributed font files.
See `Orbitron-OFL.txt` and `ScienceGothic-OFL.txt` for copyright notices and full terms.
