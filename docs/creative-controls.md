# Content preferences

Tell your agent the mix you want in the project chat.
The agent saves it in the brand profile.
The optional **Settings → Content preferences** screen provides the same controls.
The selected rules travel with the brand profile and every agent task.

## Types and exact counts

Choose funny posts, facts, history, themes, news, trends, comparisons, health, surprising facts, or posts for friends.
The friend options suggest a useful share or a relevant comment.
They do not require tags or promise a reward.

Enter exact counts for each week:

```text
2 humor, 2 facts, 1 comparison
```

This example creates five main posts each week and ten draft slots across two weeks.
If counts exceed the chosen frequency, the plan raises the frequency and explains the change.
Unused slots draw from the selected types.
The first release supports up to seven main posts each week.

## Random and custom choices

Select **Random mix** to vary post categories.
Select **Random supported format** to vary the allowed formats.
Random CTAs draw from suitable options and exclude unconfirmed offers.
Use **Create a new random mix** to produce another saved plan variation.

Custom prompts can define a theme, format, humor style, CTA, reference, or source placement.
Use the prompt attached to the relevant choice.
Keep exact counts in the count field so the software can validate them.
Use the main custom prompt for instructions that apply across the plan.

Random choices never change account access, rights, publication permission, or verified facts.
The agent must resolve a custom format before media creation.
It must preserve the format and text treatment of a supplied reference.

## The main CTA

CTA means call to action: the action you want the viewer to take.
Choose follow, save, share, comment, visit, inquire, a confirmed offer, or no CTA.
You can choose a custom CTA or random variation.
Use one clear final action when the brief calls for it.
An image-only reference can keep the CTA in its caption.

## Fact review and public sources

Every post needs a factual review, including humor captions and image-only posts.
Check any factual claim before image creation.
If its truth remains uncertain, omit it or stop the factual draft.
Never present an uncertain statement as an established fact.

Keep fictional scenes and opinions clearly distinct from real events or measured results.
News and trends need current evidence.
Health content needs suitable authoritative guidance and necessary limits.
A surprising hook must come from verified evidence.

Ask where sources should appear: caption, final slide, each factual slide, both, or a private record only.
Keep a private claim and source record in every case.
The reviewer must confirm that the selected public placement is correct.
Do not add a text slide to an image-only reference without the user's instruction.

The application checks records and review status.
It does not perform an independent scientific or historical fact check.
The reviewer must read the sources and inspect the final post.
